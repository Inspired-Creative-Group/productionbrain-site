# Product marketing context — The Memory Machine (ICG)
Written 2026-09-10 from the product brief (vault: projects/products/agentic-memory-system/memory-machine-brief-2026-09-09.md). Read by the copywriting / copy-editing / cro skills.

## The offer
One machine (a Mac Studio) installed in the client's studio that remembers everything for every AI tool they use. Installed by hand, maintained remotely by ICG over a private encrypted network, it keeps its own notes (indexes the client's documents and connected tools, checks itself every night for stale or contradicting memories, never deletes). Sold as a build fee plus a monthly care plan; hardware bought by the client at Apple's price; 90-day money-back on the build fee. Three tiers: Solo $5,900 + $490/mo; Studio $12,000 + $1,200/mo; Company from $25,000 + $2,500/mo.

## Audience (ICP)
AI-forward multimedia producers and small studios (video, design, audio): solo producers, and creative directors / studio leads with experimental budget spending company money. They already work inside Claude Code, Codex, Cursor, claude.ai, ChatGPT, Perplexity. Validated pains (Volta discovery interviews, Aug 2026): every tool remembers only its own corner; the producer is the one re-explaining context on every job; the memory they do have is rented (inside a vendor, priced per seat); they want ownership and portability. Objections heard: "my tools already have memory now" (true, but walled), "I could build this myself" (builders are in build mode, not buy mode; the value is the upkeep), "what happens if it breaks".

## Differentiation (true today)
- Local models, nothing leaves the building, $0 per memory. Private encrypted network (Tailscale); self-hosted network as a paid option.
- The machine maintains itself on a schedule (nightly staleness/contradiction/duplicate checks, weekly store audit). Nobody else in the comparison does this (BinarCode sells files + Claude; The AI Consultancy sells a Hermes assistant on a Mac mini).
- Every memory records where it came from (provenance, write-ahead log).
- Any tool plugs in over MCP; the client keeps their tools.
- Proof: ICG has run this on its own two machines since June 2026 (~7,000 memories, 1,900 notes indexed); a 14-minute video (youtu.be/4EOZkllNoDw) shows fresh ChatGPT/Grok/Perplexity accounts answering questions about real work with nothing pasted in.

## Not true yet (never claim)
Scheduled pulls from Notion/Drive (built at setup, first on ICG's own workspace); per-person attribution and access rules (Studio tier roadmap); "every conversation recorded".
